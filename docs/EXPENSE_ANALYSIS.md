# 当前消费统计口径

有效日常支出，以及repaymentConsumption开启的实际还款，是消费正数；到账退款按现有规则冲减原消费，用实际到账日和原消费当前分类／性质。转账、收入、余额校准、未开启统计的还款不参与消费。创建负债不产生购买消费，也不扣现金。

组合固定消费按recurringOccurrenceId、组合还款按repaymentId去重笔数，账户金额相加，不另生成重复支出。未判断、未分类不遗漏。分类、必要性、趋势和预算复用ExpenseIndex及统一谓词；历史修改、撤销和退款重算受影响月份。开启或关闭合同统计默认只影响未来快照，显式历史同步才修改旧还款属性，原金额、日期和现金不变。

双环外圈分类、内圈必要／非必要／未判断，净退款或非正分类净额时，两圈统一按消费原额解释占比，金额仍显示净消费。预算没有配置则不虚构额度。异常提示采用可解释规则，数据不足不强行评价消费合理性。
